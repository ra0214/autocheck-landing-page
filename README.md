## Sobre el Proyecto

Este repositorio contiene la **Landing Page** oficial de presentación para **AutoCheck OCR**. El objetivo de este sitio es proporcionar contexto técnico, social y funcional al comité evaluador sobre la propuesta de Proyecto Integrador de 9° cuatrimestre.

**AutoCheck OCR** es una solución diseñada para combatir el fraude en la compra-venta de vehículos usados en el estado de Chiapas, permitiendo la validación de facturas y Números de Identificación Vehicular (VIN) de manera autónoma.

---

## Propuesta Tecnológica

A diferencia de las soluciones convencionales, nuestro sistema destaca por:

- **Independencia Tecnológica:** No utilizamos APIs de terceros (OpenAI, Gemini) para las funcionalidades clave. Todo el procesamiento de **Machine Learning** y **NLP** se ejecuta de manera local.
- **Arquitectura Robusta:** Diseñado bajo una **Arquitectura Orientada a Servicios (SOA)** con microservicios en **Go**.
- **Enfoque en Seguridad:** Implementación de protocolos de validación forense para detectar alteraciones digitales en documentos físicos.

### Stack Tecnológico del Sistema Core:
* **Backend:** Go (Golang) + PostgreSQL.
* **Frontend Móvil:** Flutter.
* **IA/ML:** Modelos locales de visión artificial y procesamiento de lenguaje natural.
