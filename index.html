Auditoría de legalidad vehicular mediante OCR y Machine Learning local

Prevención de fraudes en la documentación automotriz.

9no Cuatrimestre Proyecto Integrador

La Problemática

Fraude Documental

Proliferación de facturas apócrifas y alteración de Números de Identificación Vehicular (VIN) en transacciones entre particulares.

Vulnerabilidad Social

Pérdidas económicas significativas y problemas legales para compradores de buena fe.

Nuestra Solución

Ecosistema autónomo de auditoría técnica sin dependencia de APIs externas.

OCR Local

Extracción de metadatos de facturas físicas con Tesseract/EasyOCR local.

Validación ISO 3779

Algoritmo matemático propio para verificar la integridad del dígito verificador del VIN.

Seguridad Forense

Detección de inconsistencias digitales en documentos mediante análisis de ruido de imagen.

Arquitectura & Stack

Frontend: Flutter
Backend: Go (SOA Microservices)
Base de Datos: PostgreSQL (SQL)
IA: ML Local (Sin APIs Externas)
