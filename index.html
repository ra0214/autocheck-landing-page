Auditoría de legalidad vehicular mediante OCR y Machine Learning local

Prevención de fraudes en la documentación automotriz sin dependencias externas.

9no Cuatrimestre Proyecto Integrador

La Problemática

Fraude Documental

Proliferación de facturas apócrifas y alteración de Números de Identificación Vehicular (VIN) en transacciones de autos usados.

Vulnerabilidad Social

Pérdidas económicas significativas y severos problemas legales para compradores de buena fe.

Nuestra Solución

Ecosistema autónomo de auditoría técnica basado en microservicios.

OCR Local

Extracción de metadatos de facturas físicas con Tesseract/EasyOCR local.

Validación ISO 3779

Algoritmo matemático automatizado en Go para verificar el dígito verificador del VIN.

Seguridad Forense

Detección de inconsistencias digitales en documentos mediante análisis de ruido de imagen.

Alcances del Proyecto

Fase 1: MVP Core

Procesamiento analítico de facturas de origen, cálculo matemático del algoritmo de validación del VIN y emisión de reportes técnicos con firmas hash SHA-256 no repudiables.

Fase 2: Escalabilidad

Arquitectura SOA desacoplada y lista para migrar a servicios en la nube (AWS), permitiendo la integración futura con bases de datos públicas de reportes de robo.

Usuarios Clave

Peritos y Auditores

Especialistas técnicos que requieren optimizar y validar la autenticidad de la documentación en minutos.

Compradores Particulares

Usuarios finales que buscan certeza jurídica inmediata antes de realizar una transacción monetaria.

Lotes de Autos Usados

Comercios medianos que necesitan blindar su inventario contra vehículos de procedencia ilícita.

Modelo de Monetización

Pago por Consulta (B2C)

Microtransacciones accesibles para usuarios particulares que requieren una auditoría exprés en un momento específico.

Suscripción Mensual (B2B)

Planes SaaS corporativos dirigidos a lotes de autos y agencias con consultas ilimitadas y reportes personalizados.

Arquitectura & Stack

Frontend: Flutter
Backend: Go (SOA Microservices)
Base de Datos: PostgreSQL (SQL)
IA: ML Local (Sin APIs Externas)
